# Support

The README covers installation, the entry points and the examples.

For help with the package, open a question or bug report in
[GitHub issues](https://github.com/stateforge-labs/herdr-sdk/issues/new/choose).
Use the form that fits: a bug report asks for the herdr version, the protocol, the runtime and a minimal snippet.

Help is best effort. There is no response time guarantee for support.

Do not report security vulnerabilities in an issue. Use the process in [SECURITY.md](SECURITY.md).

Changes to the code go through the process in [CONTRIBUTING.md](CONTRIBUTING.md).
